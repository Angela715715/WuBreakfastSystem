# 🍳 吳家早餐店點餐系統 (Breakfast Ordering System)

## 📌 專案介紹
本專案使用 **Java Swing** 開發，模擬早餐店的點餐流程。使用者可以輸入顧客姓名及餐點數量，系統會自動計算總金額、產生訂單明細，並提供列印與隨機推薦餐點等功能。


- Java 物件導向設計（OOP）
- Getter / Setter 的使用
- 類別與物件的建立
- Java Swing 圖形化介面 (GUI)
- 事件監聽 (Event Listener)
- Timer 與日期時間顯示
- 列印功能實作

## ✨ 功能特色

### 1. 點餐功能
- 輸入顧客姓名。
- 輸入各項餐點數量。
- 自動計算訂單總金額。

### 2. 訂單明細
- 顯示顧客名稱。
- 顯示各餐點購買數量。
- 顯示總金額。

### 3. 一鍵清除
- 清空所有輸入資料。
- 重置推薦結果與訂單內容。

### 4. 今日推薦
- 隨機推薦一項早餐。
- 提供選擇困難症患者參考。

### 5. 即時時間顯示
- 介面上每秒更新目前時間。

### 6. 列印功能
- 可直接列印訂單明細。

---

## 🚀 執行方式

1. 將專案匯入 Eclipse。
2. 找到 `EggUi.java`。
3. 執行 `main()` 方法。
4. 開啟圖形化介面後即可開始點餐。

---

## 🧩 類別說明

### Egg.java
負責儲存訂單資料，包括：
- 顧客姓名
- 各餐點數量
- 訂單總金額計算

### EggUi.java
負責建立 Swing 使用者介面，包括：
- 點餐畫面
- 按鈕事件處理
- 時間顯示
- 訂單輸出
- 列印功能
